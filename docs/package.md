# Documentation for lagga Python API

`lagga` exports two functions which can be used in place of the recommended command line workflow:

---

## ::: lagga.step1.step1
    handler: python
    options:
      show_root_heading: true
      show_source: true


## ::: lagga.step2.step2
    handler: python
    options:
      show_root_heading: true
      show_source: true
