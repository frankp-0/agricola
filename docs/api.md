# agricola Python API

`agricola` exports two functions which can be used in place of the recommended command line workflow:

---

## ::: agricola.step1.step1

    handler: python
    options:
      show_root_heading: true
      show_source: true

## ::: agricola.step2.step2

    handler: python
    options:
      show_root_heading: true
      show_source: true
